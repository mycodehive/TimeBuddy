TimeBuddy v0.1.2
Windows 10/11, Windows PowerShell 5.1, .NET Framework 4.x

설치 및 업데이트
1. 기존 프로그램이 실행 중이면 트레이의 프로그램 종료 메뉴에서 부모 비밀번호로 종료합니다.
2. 압축을 풀고 Install.bat을 실행합니다. TimeBuddy의 기존 settings.json은 유지됩니다. 이전 ChildPCGuard 설정은 자동 이전되지 않습니다.
3. 처음 설치하는 경우 부모 비밀번호를 등록합니다.
4. 트레이 > 부모 설정에서 기본 요일별 시간대와 Telegram 토큰, 개인 Chat ID를 저장합니다.
5. 트레이 > 고급 사용 관리에서 일일 제한(기본 120분, 0=무제한), 추가 시간대, 원격제어 사용 여부를 설정합니다.
6. 트레이 > 텔레그램 테스트를 이용합니다. 전용 봇과 개인 채팅을 사용하세요. 다른 프로그램에서 같은 봇의 getUpdates를 호출하거나 webhook을 설정하면 원격제어가 작동하지 않을 수 있습니다.
7. 프로그램을 시작하거나 봇 설정을 바꾼 뒤 첫 조회에서는 이전 명령을 무시합니다. 잠시 기다린 뒤 새 명령을 보내세요. 연결이 실패하면 최대 60초 간격으로 다시 시도합니다.

원격 명령 (등록된 개인 Chat ID 및 발신자 ID 일치 시만 처리)
/lock : 즉시 잠금 (재시작 후에도 유지)
/unlock [분] : 설정된 기본 시간 또는 지정한 1~720분 동안 잠금 해제
/extend 분 : 현재 허용 종료시간을 기준으로 1~120분 연장
/status : 현재 사용 가능 여부, 종료 예정 시간과 통계
/usage : 오늘/이번 주/이번 달 통계
/help : 명령 목록
부모의 비밀번호 또는 원격 승인 시간에는 일일 제한과 시간표를 예외 처리합니다. 승인 시간은 재시작하면 사라집니다.

트레이 > 나의 시간 기록에서는 최근 7일 또는 30일의 날짜별 사용 시간을 그래프로 볼 수 있습니다.
통계는 잠금이 풀려 있는 실행 시간을 측정하며 키보드/마우스 활동 시간과는 다릅니다. 절전 등 타이머 공백은 제외합니다. 약 10초마다 저장합니다. 갑작스러운 종료 시 일부 손실될 수 있습니다.

자동 업데이트
설치된 0.1.1부터 하루에 한 번 GitHub 정식 릴리스를 확인합니다. 부모 비밀번호로 트레이 > 업데이트 설정에서 켜거나 끌 수 있습니다. 새 버전의 Guard.ps1은 GitHub가 제공한 SHA-256과 대조한 뒤 저장되며 다음 실행 때 적용됩니다. 이전 스크립트는 %LOCALAPPDATA%\TimeBuddy\Guard.ps1.previous에 보관됩니다.
0.1.0에서 0.1.1로 올릴 때는 기존 앱을 종료한 뒤 이 버전의 Install.bat을 한 번 실행해야 합니다.

EXE 제작: Windows에서 Build_EXE.bat 실행 -> TimeBuddy_Setup.exe 생성. 본 패키지는 사전 컴파일된 EXE가 아닙니다. 별도 서명은 없습니다.

주의: 실제 Windows 및 Telegram 통합 실행 테스트 미실시. 일반 사용자 수준의 화면 차단 프로그램으로 작업 관리자, 시스템 보안 화면, 설정 파일 변경 등에 의해 우회될 수 있습니다. 강제 종료나 OS 보안 기능 차단은 하지 않습니다. 자녀 계정은 표준 사용자로 운영하고 Windows Family Safety를 병행하세요. 프로그램 종료는 트레이에서 부모 비밀번호를 입력합니다. 삭제는 아래 안내를 따릅니다. 설정과 통계는 %LOCALAPPDATA%\TimeBuddy 에 있습니다.


0.1.2 설치 및 삭제
기존 앱 종료 후 Install.bat을 다시 실행해야 삭제 메뉴 및 등록이 적용됩니다. 자동 업데이트는 Guard.ps1만 교체합니다.
잠금화면 확인: 트레이 > 잠금화면 테스트 (10초), 부모 비밀번호 입력. 허용 시간에는 10초 후 닫히며, 제한 시간에는 정상 잠금이 유지됩니다. 오류 기록: %LOCALAPPDATA%\TimeBuddy\timebuddy.log
삭제: 트레이 > 프로그램 종료 후 Windows 설정 > 앱 > 설치된 앱 > TimeBuddy > 제거 (또는 시작 메뉴 TimeBuddy Uninstall). 부모 비밀번호를 입력하고 예/아니요로 데이터 삭제/보존을 선택하세요. Windows 자체 보안 화면을 차단하지 않습니다.
